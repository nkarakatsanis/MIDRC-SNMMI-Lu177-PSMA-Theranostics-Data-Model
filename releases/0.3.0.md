# SNMMI-MIDRC Lu177-PSMA theranostics data model — 0.3.0

Initial development release of the Lu177-PSMA theranostics extension, organized using the MIDRC Gen3 data dictionary conventions.

## Contents

- 67 node types and 293 relationships: 29 retained MIDRC baseline nodes and 38 proposed theranostics nodes.
- Optional additions to 17 baseline nodes, with seven proposed enum additions documented separately.
- Complete JSON/YAML schemas, submission templates, source crosswalks, migration mappings, graph exports and additive integration patch.
- Human-readable architecture, domain index, node catalog and field-by-field dictionary pages for all 67 nodes.
- Nine patient-journey stages, five use cases and 122 entirely synthetic linked records.
- Standalone v0.3.0 interactive HTML explorer and Word architecture document, matching the files inside the model archive.

## Version and compatibility

Lu177-PSMA theranostics data model release 0.3.0 extends the deployed MIDRC Gen3 dictionary version `1.4.3-2-g7505333`, commit `7505333d56c87a289463a814131e38d0f2be6674`, retrieved on 16 October 2026. The baseline snapshot and its SHA-256 checksum are preserved in this release.

The release version and title are **0.3.0**; its Git tag is **v0.3.0**. Inherited MIDRC tags have since been removed from this repository; `v0.3.0` identifies the initial theranostics model release. The working-model identifier `0.3.0-proposal` records its review status.

The imported `gdcdictionary/` source is retained, including the existing PET/MR `mr_images` property. The complete proposal lives in `extensions/lu177_psma/v0.3.0/`. Its pinned deployed MIDRC baseline is distinct from this repository's imported source revision; reconcile the two before live integration.

## Validation and review status

Local validation covers 67 schemas and templates, 921 source occurrences, 122 synthetic records, 29 baseline regression fixtures and 27 invalid-case checks. All pass. Download checksums are supplied in `SHA256SUMS.txt`.

This is a development release for technical and working-group review. Live Gen3 compilation, migration and submission testing, clinical review, and terminology/ontology-owner approval remain pending. No MIDRC service is deployed by this release.
