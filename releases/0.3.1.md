# SNMMI-MIDRC Lu177-PSMA theranostics data model — 0.3.1

Documentation-only patch of release 0.3.0. The release title is **0.3.1** and its Git tag is **v0.3.1**.

## MIDRC baseline provenance

Lu177-PSMA theranostics data model release 0.3.0 extends the deployed MIDRC Gen3 dictionary version `1.4.3-2-g7505333`, commit `7505333d56c87a289463a814131e38d0f2be6674`, retrieved on 16 October 2026. The baseline snapshot and its SHA-256 checksum are preserved in this release.

Release 0.3.1 packages the same model against the same pinned baseline. The imported `gdcdictionary/` source is a distinct revision, retained from parent `bee947238381704486ccd12beeb8f4689fb22843`; reconcile it with the compiled deployed baseline before live integration.

## Documentation changes

- State the complete MIDRC baseline in the changelog and release notes.
- Correct outdated inherited-tag wording. The initial theranostics release remains tagged `v0.3.0`; inherited MIDRC tags have been removed from this repository.
- Update the published v0.3.0 release description and retain its original tag and assets.
- Update the README, repository guide, release metadata and ZIP packaging to identify this documentation patch.

## Model and validation status

Every file in `extensions/lu177_psma/v0.3.0/` and `gdcdictionary/` is unchanged from v0.3.0. The 67 node types, 293 relationships, property definitions, examples, baseline snapshot, HTML explorer and Word architecture document are unchanged. The working-model identifier remains `0.3.0-proposal`; no schema migration is required by this patch.

Validation checks include model-file checksum preservation, generated dictionary-page consistency and release packaging. The existing model validation also runs in the release workflow. Live Gen3 integration and clinical/terminology review remain pending; this is a development release.
