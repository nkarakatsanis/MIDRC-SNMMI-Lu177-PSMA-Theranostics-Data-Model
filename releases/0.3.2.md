# SNMMI-MIDRC Lu177-PSMA theranostics data model — 0.3.2

Documentation-only follow-up to release 0.3.1. The release title is **0.3.2** and its Git tag is **v0.3.2**.

## MIDRC baseline provenance

Lu177-PSMA theranostics data model release 0.3.0 extends the deployed MIDRC Gen3 dictionary version `1.4.3-2-g7505333`, commit `7505333d56c87a289463a814131e38d0f2be6674`, retrieved on 16 October 2026. The baseline snapshot and its SHA-256 checksum are preserved in this release.

## Changes

- Update the supplied Word architecture document and HTML explorer with the exact baseline statement, full commit, retrieval date, snapshot checksum and corrected release/tag history.
- Align cover, footer, HTML header and standalone download filenames with documentation release 0.3.2.
- Add an accessible, expandable release-history section to the HTML explorer and a release-history page to the Word document.
- Update the documents at their existing repository paths under `extensions/lu177_psma/v0.3.0/`, plus packaging provenance, validation records and checksums.
- Refresh the README and human-readable references. The 0.3.0 and 0.3.1 tags and their original download assets are retained.

## Unchanged model

The model schema revision remains **0.3.0-proposal**: all JSON/YAML schemas, templates, definitions, graph data, examples, source snapshots and imported `gdcdictionary/` files are unchanged. The HTML's embedded model JSON and application JavaScript are unchanged. This patch requires no schema migration. The model and its NucLex alignment remain under development, with live Gen3 integration and clinical/terminology-owner review pending.
